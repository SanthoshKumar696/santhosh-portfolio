# Santhosh Kumar — Developer Portfolio

A responsive developer portfolio built with React and Vite. It includes a full-stack and AI-focused introduction, an interactive technology showcase, four project case studies, practical experience, education, a development process, and contact links.

## Run locally

```sh
npm install
npm run dev
```

## Personalize before publishing

- In `src/App.jsx`, replace `LINKEDIN_URL` and `GITHUB_URL` with Santhosh's actual profile URLs.
- The contact form uses `mailto:` to prepare a message in the visitor's email application. It does not submit to or store data on a backend. Configure a real form service or server endpoint before claiming in-site delivery.
- The resume download is a plain-text profile because no original resume file was provided. Replace `public/Santhosh-Kumar-Resume.txt` with an approved PDF resume and update the link in `src/App.jsx` when available.
- Confirm the education institution and current study status before publishing; the portfolio marks the institution as unconfirmed.
- BuildZentra modules are labelled as planned and not represented as live.

npm run build
